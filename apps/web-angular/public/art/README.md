# Battle artwork

Generated with the built-in Imagegen tool for the OpsFlow console. The courtyard is decorative; the character atlas supplies five CSS frames. Run states and metrics are rendered by Angular from the backend.

- `battle-courtyard.png`: background for Battle View, including its empty state.
- `battle-roster.png`: knight, timeout wraith, HTTP demon, Redis machine and duplicate scheduler, left to right.

## Courtyard prompt

Use case: stylized-concept. Asset type: background for an operational dashboard pixel-art battle arena. Create a polished detailed 16-bit pixel-art wide landscape, dark gothic castle courtyard at midnight, ruined stone towers in the distance, large luminous blue moon high near the center, twisting bare branches at the sides, small warm torch flames, dark navy and desaturated blue palette. Side-view video game battle stage, an uninterrupted stone platform at 88% of image height across the full width, spacious empty foreground above the platform for characters that will be overlaid in code. Strong readable pixel clusters, moody layered depth. Wide 3:1 composition. No characters, no creatures, no text, no letters, no UI, no logos or watermark. Background should be atmospheric but relatively dark so overlaid UI is readable.

## Character prompt

Use case: stylized-concept. Asset type: transparent game character atlas for a pixel-art operational battle dashboard. Make exactly FIVE equally sized square cells in ONE HORIZONTAL ROW, overall 5:1 aspect ratio, transparent background throughout. Each full-body character centered in its own cell, feet aligned at 90% cell height, each fits entirely in its own cell with generous padding. From LEFT TO RIGHT: 1 blue-caped silver knight facing right, holding a silver sword and blue shield; 2 floating hooded purple ghost wraith with glowing violet hands; 3 red horned fire demon facing left with yellow eyes; 4 moss green cubic mechanical robot with glowing red eyes; 5 dark hooded sentinel with an orange face. Detailed professional 32-bit pixel-art sprites with crisp clusters, dramatic moonlit shading, cohesive proportions, retro gothic side-scrolling game style. NO floor, NO background scene, NO words, NO labels, NO borders, NO UI. Real transparent alpha background, no checkerboard drawn. Keep characters strictly within five equal width cells so CSS can select each frame.
