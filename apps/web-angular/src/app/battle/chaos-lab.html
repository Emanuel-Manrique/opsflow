Infrastructure tests

A worker crash, a Redis outage and a scheduler race are infrastructure events. Rather than fake a button for them, run these and watch the console react: 

docker compose stop redis     # outbox holds; runs resume on restart
docker compose start redis
pnpm nx serve orchestrator    # a second instance: SKIP LOCKED keeps one run per occurrence

⚠ Chaos mode is available only in non-production environments.
